# Tapeta na ścianie

Strona do wizualizacji tapety na zdjęciu pokoju: zdjęcie pokoju, cztery rogi ściany,
zdjęcie tapety, poprawki gumką, zapis albo udostępnienie.

Zdjęcia są przetwarzane tylko w przeglądarce i nigdzie nie są wysyłane.

- Strona: https://laaidback.github.io/tapeta/
- Lokalnie: `npm run serve`, potem http://localhost:8123/ (`?demo` wczytuje sztuczny pokój)
- Testy: `npm test`
- Projekt: `docs/superpowers/specs/2026-11-11-tapeta-design.md`
